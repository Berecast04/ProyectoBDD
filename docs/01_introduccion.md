# Introduccion

La Encuesta Nacional de Ocupacion y Empleo (ENOE) del INEGI es una de las fuentes oficiales mas importantes para estudiar el mercado laboral mexicano. Contiene informacion sobre ocupacion, desocupacion, fuerza laboral, caracteristicas sociodemograficas y condiciones laborales de la poblacion de 15 anios y mas.

El proyecto utiliza datos historicos de ENOE para construir primero una base centralizada y despues una base distribuida. La finalidad es demostrar que una distribucion correctamente disenada puede dividir una tabla grande en fragmentos independientes sin perder consistencia logica ni resultados analiticos.

# Objetivo general

Disenar, implementar y validar una base de datos centralizada y distribuida usando informacion historica de la ENOE.

# Objetivos especificos

- Extraer datos historicos de ENOE.
- Procesar y optimizar datos en Parquet.
- Disenar un modelo OLTP normalizado.
- Implementar una base centralizada.
- Crear consultas de analisis.
- Disenar una estrategia de distribucion.
- Fragmentar los datos.
- Ejecutar consultas distribuidas.
- Validar los resultados.
