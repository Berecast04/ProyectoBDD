# Documentacion oficial

La documentacion vigente del proyecto esta en:

- `latex_entrega/proyecto_enoe_bdd.tex`
- `latex_entrega/figuras/`
- `latex_entrega/consultas/`

El documento incluye instalacion desde cero, arquitectura centralizada y
distribuida, las 82 evidencias, comparacion de rendimiento, respaldos y
conclusiones.

## Compilar

Con MiKTeX o TeX Live:

```powershell
cd docs/latex_entrega
pdflatex proyecto_enoe_bdd.tex
pdflatex proyecto_enoe_bdd.tex
```

Tambien se puede subir la carpeta `latex_entrega` completa a Overleaf.

Los Markdown anteriores se conservaron solo de forma local durante la
preparacion, pero no forman parte de la entrega vigente.
